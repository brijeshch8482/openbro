# OpenBro — live demo

Ask OpenBro a question and watch it plan, call tools and answer, step by step.

This Space runs `openbro web` from [github.com/brijeshch8482/openbro](https://github.com/brijeshch8482/openbro).
Visitors get a locked-down agent: web search, date/time and search over OpenBro's
own documentation. The full agent — shell, files, apps, a real browser, voice,
memory — runs on your own machine: `pip install openbro`.
